# Movie Explorer

Responsive Flutter web app (Provider state management, named routes, animations, forms with validation).

Demo login: demo@movie.com / demo123 (or use "Continue as guest").

Run locally (needs Flutter):
    flutter create . --platforms web
    flutter pub get
    flutter run -d chrome

Deployment: every push to `main` is built and published to GitHub Pages by .github/workflows/deploy.yml.
